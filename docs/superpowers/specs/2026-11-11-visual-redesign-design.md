# Guardy 視覺改版設計規格

日期：2026-11-11
狀態：設計已確認，待實作

## 1. 目標與範圍

**目標**：把 Guardy 的外觀從「米黃底＋手繪插圖」改成「清楚俐落為主、親切有人味為輔」的風格。讓第一次出車禍、正在慌張的人，一打開就看得到重點。

**範圍內**
- 五個分頁（現場、存證、保險、賠償、設定）的頁首、卡片、按鈕、清單、分頁列的視覺樣式
- 配色、背景漸層、字級、圓角
- 拿掉深色模式
- 從各分頁打開的覆蓋層（對方資料、照片檢視、確認對話框、toast、地點輸入等）同步換成新的色彩與圓角，但版面不動

**範圍外**
- 分頁結構、步驟內容、功能流程，一律不動
- 請求明細、事故紀錄的**列印版面**：維持白紙黑字，不套用漸層和品牌色
- 宣傳影片與 `screenshots/` 的截圖更新（另外處理）

**設計參考**：使用者提供的 Insightlancer 雙手機 UI 參考圖。主要借用以下做法：頂部置中的小標題、標題下的大字問候、實心主色重點卡、淡色圓形底的圖示、「標題……右側資訊」的區塊標頭。

## 2. 設計決策紀錄

| 決策 | 選擇 | 放棄的選項 |
|---|---|---|
| 改版範圍 | 視覺換新，流程不動 | 重整流程、全部重做 |
| 調性 | 清楚俐落為主、親切為輔 | 安心溫暖、專業可靠 |
| 首頁骨架 | 緊急鍵在上，步驟是一排清單（方案 A） | 深色頂部色塊、一次只顯示一步 |
| 主色 | 品牌綠（延續現有辨識度） | 信任藍、石墨＋橘、暖白＋深青 |
| 頁首 | 置中小標題，不放 logo | 左上角放 logo |
| 背景 | 上白 → 下淡綠漸層 | 上淡綠 → 下白、斜向、光暈、綠到青藍 |
| 110／119 | 淡色底＋深色字，同屬紅色系 | 實心紅黃、實心雙紅、同色、品牌綠 |
| 119 的標示 | 「救護車」 | 「有人受傷」 |
| 深色模式 | 拿掉，一律淺色 | 保留跟隨系統 |

## 3. 設計 Token

全部改寫在 `index.html` 的 `:root`。沿用現有的 token 名稱，元件 CSS 才不用跟著大改；只有新的概念才新增 token。

### 3.1 顏色

| Token | 新值 | 用途 |
|---|---|---|
| `--bg` | `#F4F9F6` | 漸層載入前的底色，也是 `theme-color` 以外的退路 |
| `--bg-grad`（新增） | `linear-gradient(180deg,#FFFFFF 0%,#F4F9F6 45%,#DDEFE5 100%)` | 頁面背景 |
| `--card` | `#FFFFFF` | 卡片底 |
| `--ink` | `#111814` | 主要文字 |
| `--ink-2` | `#2E3833` | 次要標題 |
| `--muted` | `#5E6964` | 說明文字；實作時要量對比，在漸層最綠的 `#DDEFE5` 上也要 ≥ 4.5:1，不夠就再加深 |
| `--chev` | 同 `--muted` | 箭頭 › |
| `--line` | `rgba(17,24,20,.09)` | 卡片細框 |
| `--line-soft` | `rgba(17,24,20,.05)` | 清單分隔線 |
| `--brand` | `#0F6B4E` | 品牌綠：實心重點卡、主要按鈕、選取中的分頁 |
| `--solid-bg` / `--cta-bg` | `#0F6B4E` | 同上 |
| `--solid-fg` / `--cta-fg` | `#FFFFFF` | 綠底上的字 |
| `--green-bg`（改值） | `#D3E7DC` | 圖示的淡綠圓形底、步驟數字圓點 |
| `--green-ink` | `#0F6B4E` | 淡綠底上的圖示與數字 |
| `--red` | `#B4142C` | 110 文字與圖示、刪除類操作 |
| `--red-bg` | `#FDE7E9` | 110 底色、刪除類圖示底 |
| `--red-line` | `#F6C4CA` | 110 框線 |
| `--amber` | `#C2410C` | 119 文字與圖示 |
| `--amber-bg` | `#FFEDE8` | 119 底色 |
| `--amber-line` | `#F8CDBF` | 119 框線 |
| `--chrome` | `rgba(255,255,255,.92)` | 分頁列底色 |

`--head-bg`、`--head-line`、`--brand-lite`、`--hero-fade*` 這幾個 token 只給舊的頁首色塊和插圖用，改版後一併刪除。

### 3.2 字級

這些是手機上的實際大小。輸入框維持 ≥ 16px，避免 iOS 點下去時自動放大畫面。

| 層級 | 大小／字重 | 用在哪裡 |
|---|---|---|
| 頁面標題（置中） | 17px／700 | 每頁最上方 |
| 問候、大標 | 24px／800 | 「別慌，」「資料先問到手」等 |
| 金額大字 | 34px／800 | 賠償頁小計 |
| 區塊標題 | 16px／800 | 「現場處理」「拍照清單」 |
| 重點卡標題 | 18px／800 | 目前這一步 |
| 卡片標題 | 15px／700 | 清單每一列 |
| 內文 | 14px／400 | 步驟說明 |
| 副標、輔助文字 | 12.5px／400 | 清單副標、區塊右側的進度 |
| 分頁列 | 11px／500，選取中 700 | 底部分頁 |

字型沿用現有的系統字型組合，不額外載入網路字型。這樣離線時一樣能正常顯示。

### 3.3 圓角與陰影

- 一般卡片、清單列：16px
- 實心重點卡、緊急鍵：18px
- 頁首的大卡（設定頁的品牌卡、賠償頁的小計卡）：22px
- 卡片內的小按鈕：12px
- 白卡加一層很淡的陰影 `0 1px 3px rgba(17,24,20,.05)`，搭配細框。漸層往下變綠時，卡片邊界才看得出來

## 4. 共用元件

### 4.1 頁首

```
┌──────────────────────────┐
│          事故現場          │  ← 置中，17px，不放 logo
│                          │
│ (頭像) 別慌，              │  ← 問候區：每頁內容不同（見第 5 節）
│        我陪你一步一步處理。  │
```

- 拿掉現在 `.page-head` 的米黃色塊、GUARDY 品牌字和插圖背景（`hero.jpg`）
- 頁首不再有底色，直接疊在漸層上

### 4.2 區塊標頭

左邊是區塊標題（16px／800），右邊是輔助資訊（12.5px，`--muted`），例如進度「0 / 6」、「1 件」、「匯出」。取代現在的小字 `.sec-label`。

### 4.3 實心重點卡

品牌綠底、白字、18px 圓角。用在：
- 現場、保險頁的「目前這一步」：上方小字「STEP n · 現在做這一步」，右上角是勾選圓圈，下方是白底綠字的操作按鈕
- 存證頁的「記錄對方資料」
- 保險頁的「撥打出險專線」
- 賠償頁的小計卡、設定頁的品牌卡

### 4.4 步驟列（非目前步驟）

白底、細框、淡陰影。左側是淡綠圓點加綠色數字，右側是步驟標題。

做完的步驟：圓點換成實心綠底加白勾，標題加刪除線，整列不透明度降到 0.6。

### 4.5 清單列（拍照清單、金額欄、設定列）

白底卡片，左側是 38px 的淡綠圓形底加綠色線條圖示，中間是標題和副標，右側是操作：
- 拍照清單：未完成時是外框相機鍵，完成時是實心綠勾
- 金額欄：輸入框有填金額時，框線變成品牌綠
- 設定列：右側是 ›；刪除類的列，圖示底改成 `--red-bg`，圖示和文字用 `--red`

### 4.6 緊急鍵（110／119）

```
┌─────────────┐ ┌─────────────┐
│ 110          │ │ 119          │
│ 報警      🚨 │ │ 救護車    ✚ │
└─────────────┘ └─────────────┘
```

- 110：`--red-bg` 底、`--red-line` 框、`--red` 字
- 119：`--amber-bg` 底、`--amber-line` 框、`--amber` 字
- 數字 32px／800，標示 13px／700，圖示放右下角
- 119 的標示從「有人受傷」改成「救護車」，英文從 `Injuries` 改成 `Ambulance`
- 兩顆鍵維持並排，固定在問候區正下方

### 4.7 分頁列

白色半透明底加上方細線。每個分頁是線條圖示（21px）加文字，選取中的分頁圖示和文字都換成品牌綠、字重 700。圖示沿用現有的 SVG symbol。

## 5. 各頁套用

| 分頁 | 頁首標題 | 問候區 | 頂部重點卡 |
|---|---|---|---|
| 現場 | 事故現場 | 頭像（`about.png`，48px）＋「別慌，」＋「我陪你一步一步處理。」 | 110／119 → 現場處理清單（目前步驟用實心卡） |
| 存證 | 拍照存證 | 「資料先問到手」＋「對方可能先離開，車輛移動前先拍照。」 | 記錄對方資料（實心卡）；填過資料後顯示對方摘要卡 |
| 保險 | 通知保險 | 「五日內通知保險公司」＋「越早通知，理賠越順。」 | 保險公司卡（白卡，內含實心的撥號鍵） |
| 賠償 | 調解與賠償 | 不放問候，改用小計卡 | 小計卡：金額大字＋「已填項目／還沒填／求償期限 2 年」三格 |
| 設定 | 設定 | 不放問候，改用品牌卡 | 品牌卡：頭像（70px，置中）＋保險好鄰居＋介紹＋「用 LINE 找我們」白色按鈕 |

其他說明：
- **現場頁**：位置卡維持現在的位置（110／119 和現場處理之間），只換成白卡樣式。內容和行為都不變。mockup 沒有畫到位置卡，順序以現有程式為準。
- **賠償頁**：小計卡取代現在的小計區。三格裡的數字都從現有資料算出來，不新增任何儲存欄位：
  - 「已填項目」：有填金額的欄位數
  - 「還沒填」：總欄位數減掉已填數
  - 「求償期限」：固定顯示「2 年」
- **設定頁**：事故案件卡沿用現有資訊，目前的案件用品牌綠框標示，並加上「目前案件」標籤。

## 6. 拿掉深色模式

1. 刪除 `:root[data-theme="dark"]` 底下所有的覆寫，以及其他 `[data-theme="dark"]` 規則
2. 刪除 `<head>` 裡首次繪製前切換主題的腳本（`aa.theme.v1`、`window.__theme`）
3. 刪除設定頁的「外觀」區塊（`#seg-theme`），以及它的 JS
4. `<meta name="theme-color">` 改成 `#FFFFFF`，另外新增 `<meta name="color-scheme" content="light">`，並在 `:root` 加上 `color-scheme: light`。手機系統開深色模式時，表單元件才不會被系統塗成深色
5. 使用者手機裡舊的 `aa.theme.v1` 不用清，沒有程式會再讀它

## 7. 背景漸層的實作

各分頁的 `.view` 是各自捲動的，所以漸層要固定在視窗上，不能跟著內容一起捲。否則內容一長，漸層會被拉得很長，底部的綠色就看不到了。

做法：
- 在 `.views` 底下放一層 `position:fixed; inset:0; z-index:-1` 的背景，套用 `--bg-grad`
- 各個 `.view` 改成透明底

不用 `background-attachment: fixed`，因為 iOS Safari 不支援。

## 8. 英文版

只改這兩處文字：
- 119 的標示：`Injuries` → `Ambulance`
- 各頁的問候語要補上 `data-en`，延續現有中英對照的寫法

`test_i18n.py` 會掃描英文畫面上有沒有漏翻的中文，可以用它確認。

## 9. 驗證方式

1. **既有測試全部通過**：`tests/` 底下的 8 支腳本。其中兩支要配合修改：
   - `a11y.py`：拿掉深色主題的掃描迴圈，只掃淺色
   - `test_cases.py`：拿掉「設定頁有外觀切換」的檢查
2. **對比度**：`a11y.py` 實際量測。重點是 `--muted` 在漸層最綠處、緊急鍵的淡底深字、綠底白字，都要 ≥ 4.5:1
3. **觸控面積**：緊急鍵、步驟勾選圓圈、清單右側的按鈕，都要 ≥ 44px
4. **畫面比對**：用 390×844 的手機尺寸逐頁截圖，對照第 5 節確認：
   - 頁首置中、不放 logo
   - 漸層是上白下綠，而且固定在視窗上，不隨內容捲動
   - 119 顯示「救護車」
   - 設定頁沒有「外觀」區塊
5. **系統深色模式**：用深色模式模擬開啟 App，確認畫面仍是淺色，表單元件也沒有變深
6. 更新 `sw.js` 的 VERSION，讓已安裝的使用者拿到新版

## 10. 實作時的調整（2026-11-11）

實作後跟上面規格不同的地方，以這一節為準：

- `--muted` 用 `#56615C`（比規格的 `#5E6964` 深），在漸層最綠處量到 5.38:1；`--amber` 用 `#B93A0B`（比 `#C2410C` 深），在淡橘底上 5.05:1
- 分頁列文字維持 12px（規格寫 11px）：11px 在手機上太小
- 步驟列左側維持各步驟原本的圖示，放在淡綠圓形底裡，沒有改成數字。「STEP n」標籤已經有編號
- 現場頁問候的副標沿用原本的「我們陪你一步一步處理。」，跟設定頁「我們」的口吻一致
- 現場頁拿掉「緊急聯絡」小標，兩顆緊急鍵直接接在問候下面，跟 mockup 一致
- 賠償頁的「要注意的期限」橫幅保留，放在小計卡下面
- 「已完成 n / m」從清單下方搬到區塊標頭右側；「重設」鍵留在清單下方靠右
- 保險公司下拉選單下方的提示連結改成一般文字排版，修正長句時「聯絡我們」被擠成獨立一欄的問題
- `hero.jpg` 從 service worker 的離線快取清單拿掉，檔案保留在 repo 給影片素材用
